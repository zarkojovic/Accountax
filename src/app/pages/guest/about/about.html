About Accountex

Accountex is a modern, modular accounting platform built for entrepreneurs, freelancers, and accountants who value clarity, speed, and control.

🌟 Key Features

  • Modular Architecture: Built with standalone components and dynamic routing.
  • Invoice Management: Create, edit, and track invoices with category tagging.
  • Admin Dashboard: Visualize metrics with dynamic charts and statistics.
  • Role-Based Access: Secure admin panel with user roles and permissions.
  • Data Hygiene: Smart deletion of orphaned files and clean storage.
  • Responsive UI: Tailwind + DaisyUI for sleek mobile-friendly experience.

🚀 Why Accountex?

Accountex automates the boring parts of bookkeeping and empowers users with visual insights.

🔧 Built With

  • Angular 17 with standalone components
  • Supabase for real-time data and auth
  • Tailwind CSS + DaisyUI for UI consistency
  • Chart.js for dynamic data visualization
